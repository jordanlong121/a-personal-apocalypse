A PERSONAL APOCALYPSE

A roguelike built from real map data. Type any town or neighbourhood; the game downloads it once and plays offline after that.
Your places
Map data © OpenStreetMap contributors, ODbL. Downloads use the public Nominatim and Overpass services, which are run by volunteers; please be gentle with the large option. Everything is generated from building footprints, road networks and land use: interiors, loot and zombies are procedural and seeded, so a place plays the same way every time at the same seed.
